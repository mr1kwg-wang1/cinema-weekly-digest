# 영화관 주간 다이제스트 텔레그램 봇

단양작은영화관 · 양평시네마의 이번 주 상영작을 평점·박스오피스 순위·줄거리와 함께
텔레그램으로 보내주는 스크립트입니다.

## 데이터 출처

| 항목 | 출처 |
|---|---|
| 단양작은영화관 상영시간표/줄거리 | dtryx 예매 플랫폼 공개 JSON API |
| 양평시네마 상영작/줄거리 | petitecine 예매 플랫폼 공개 JSON API (단관 극장이라 최근 등록순 상위 3편을 "이번 주 상영작"으로 근사) |
| 전국 박스오피스 순위·관객수 | KOBIS(영화진흥위원회) 공공 오픈API |
| 평점 | TMDB(The Movie Database) — 두 영화관 사이트, KOBIS 모두 평점 정보가 없어 대체 |

## 준비물

1. **텔레그램 봇 토큰 / chat id** — 이미 보유 중이라고 하셨죠. `.env`에 넣어주세요.
2. **KOBIS 공공API 키** (무료)
   - https://www.kobis.or.kr/kobisopenapi/homepg/main.do 접속 → 회원가입 → "오픈API 신청" → 즉시 발급
   - 발급받은 키를 `.env`의 `KOBIS_API_KEY`에 입력
3. **TMDB API 키** (무료, 평점용)
   - https://www.themoviedb.org 가입 → 설정(Settings) → API → "Request an API Key" (개인/비상업 용도로 즉시 승인)
   - v3 API Key 또는 v4 Read Access Token 둘 다 지원 (`.env`의 `TMDB_API_KEY`)

## 설치 & 실행

```bash
npm install
cp .env.example .env   # 값 채우기
npm start
```

정상 실행되면 콘솔에 다이제스트 내용이 출력되고, 텔레그램으로 동일한 내용이 전송됩니다.

## 알려진 한계

- 양평시네마는 공식 사이트에 날짜별 상영시간표 API가 공개되어 있지 않아(단관 극장), 정확한 시간표 대신
  "최근 등록된 상영작 상위 3편"을 보여줍니다. 정확한 시간은 메시지에 안내된 홈페이지 링크로 확인해야 합니다.
- KOBIS 박스오피스는 전국 주간 상위 10위까지만 제공하므로, 순위 밖 영화(특히 예술영화/다큐)는
  "전국 박스오피스 순위 밖"으로 표시됩니다.
- TMDB 평점은 국내 관객 평점이 아닌 TMDB 자체 집계(주로 해외 이용자 포함)입니다.
